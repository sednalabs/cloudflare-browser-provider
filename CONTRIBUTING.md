# Contributing

Contributions are welcome through pull requests.

- Keep credentials, browser state, screenshots, copied page content, and local machine details out
  of commits, logs, fixtures, issues, and pull requests.
- Add tests for behavior changes and run the repository's hosted validation.
- Keep the command adapter's standard output machine-only JSON.
- Use neutral, publication-safe examples and domains reserved for documentation.
- Preserve third-party notices and provenance when adapting upstream material.

By contributing, you agree that your contribution is licensed under the Apache License, Version 2.0.
