# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities through this repository's private security-advisory form. Do
not open a public issue for a vulnerability and do not include credentials, browser content, session
identifiers, screenshots, or other private data in public discussions.

Reports should include the affected version, a minimal reproduction, expected and observed behavior,
and any safe remediation ideas. Maintainers will acknowledge a complete report as soon as practical
and coordinate disclosure after a fix is available.

## Supported versions

Until the first stable release, security fixes are applied to the latest published release and the
default branch.
